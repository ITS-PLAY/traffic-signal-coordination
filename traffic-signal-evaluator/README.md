# 交通信号评估器 (Traffic Signal Evaluator)

**基于微观仿真与统计分析的信控方案评估系统**

## 概述

交通信号评估器是一个先进的交通控制系统评估平台，通过**因果性仿真**（SUMO微观仿真）和**相关性分析**（统计学方法）相结合的方式，对交通信号控制方案、点线面规划合理性进行全面评估。

本系统支持：
- **单点交叉口**信控方案评估
- **干线协调**（绿波带）方案评估  
- **区域协调**控制方案评估
- **多维度指标**综合评价体系

## 评估方法论

### 1. 因果性评估 (Causal Evaluation)

通过**微观交通仿真**建立因果关系模型：

- **输入**: 信控方案、路口渠化、交通流量、道路几何
- **过程**: SUMO微观仿真，模拟每个车辆的行为
- **输出**: 精确的交通运行指标

**优势**: 
- 建立严格的因果关系
- 考虑复杂的交通行为交互
- 支持"what-if"场景分析

### 2. 相关性评估 (Correlation Evaluation)

通过**统计学方法**分析历史数据模式：

> **注意**: 当前版本主要实现因果性仿真评估，相关性/Look-Alike分析功能待扩展

**计划支持的功能**:
- 历史流量模式识别
- 相似场景匹配 (Look-Alike Modeling)
- 统计显著性检验
- 多变量回归分析

## 输入数据格式

系统接受JSON格式的输入配置，包含以下关键信息：

### 基础结构
```json
{
  "crossList": ["C0", "C1", "C2"],
  "roadLength": [526, 480],
  "roadSpeed": [[57, 62], [64, 58]],
  "crossInfo": {
    "C0": "1,422,2|2,441,2|3,221,2;A3212|B14|C25",
    "C1": "1,4223,2|2,C6223,3|3,4223,3|4,C6221,3;A2242|B2C4C|C3212|D3414"
  },
  "planInfo": {
    "C0": "A59B32C39,A10",
    "C1": "A38B30C33D29,C30"
  },
  "crossFlow": {
    "C0": {"21": 55, "24": 85, "28": 20, "14": 35, "18": 40, "12": 140, "31": 85, "38": 20, "32": 125},
    "C1": {"21": 60, "24": 140, "28": 65, "22": 460, "11": 115, "14": 95, "18": 35, "12": 80, "31": 160, "34": 60, "38": 20, "32": 75, "41": 50, "44": 95, "48": 105, "42": 360}
  }
}
```

### 字段说明

- **crossList**: 路口ID列表，按顺序排列（用于干线协调）
- **roadLength**: 路口间路段长度（米）
- **roadSpeed**: 路段速度设置，`[[正向速度], [反向速度]]`（km/h）
- **crossInfo**: 路口详细信息，格式为 `"渠化信息;相位信息"`
  - **渠化信息**: `方向ID,车道转向,出口道数`，用`|`分隔
    - 车道转向: 十六进制编码（4位二进制：掉头、左转、直行、右转）
    - 示例: `422` = `0100 0010 0010` = 左转、直行、直行
  - **相位信息**: `相位ID+转向信息`，用`|`分隔
    - 示例: `A3212` = 相位A，方向3允许转向2（直行），方向2允许转向1（右转）
- **planInfo**: 信控方案，格式为 `"相位时长,协调相位偏移"`
  - 示例: `A59B32C39,A10` = A相59秒、B相32秒、C相39秒，协调相位A，偏移10秒
- **crossFlow**: 交通流量，格式为 `"方向+转向": 流量(veh/h)`

## 输出指标

系统提供多维度的评估指标：

### 1. 宏观指标
- **平均行程速度**: 整体/正向/反向 (km/h)
- **平均停车率**: 车辆停车比例
- **平均排队长度**: 各进口道排队情况
- **平均行程时间**: 起点到终点的行程时间

### 2. 微观指标
- **单车轨迹数据**: 时空轨迹、速度变化
- **停车次数统计**: 每车平均停车次数
- **等待时间分布**: 各类等待时间统计
- **排队动态**: 实时排队长度变化

### 3. 协调效果指标
- **绿波带效果**: 正向/反向协调效果对比
- **相位差优化**: 不同相位差方案比较
- **通行效率提升**: 相对于基准方案的改善程度

## 快速开始

### 环境要求
- Python 3.7+
- SUMO 1.8.0+
- Docker (可选，用于容器化部署)

### 安装依赖
```bash

pip install xmltodict pandas numpy

# 安装SUMO (Ubuntu/Debian)
sudo add-apt-repository ppa:sumo/stable
sudo apt-get update
sudo apt-get install sumo sumo-tools
```

### 插件架构
