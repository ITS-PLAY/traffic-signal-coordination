# 输入数据格式详细说明

## 1. 基础结构

输入数据为JSON格式，包含以下顶层字段：

| 字段 | 类型 | 必填 | 描述 |
|------|------|------|------|
| `crossList` | Array[String] | 是 | 路口ID列表，按空间顺序排列 |
| `roadLength` | Array[Number] | 是 | 路口间路段长度（米） |
| `roadSpeed` | Array[Array[Number]] | 否 | 路段速度设置 [[正向], [反向]] (km/h) |
| `crossInfo` | Object | 是 | 各路口详细信息 |
| `planInfo` | Object | 是 | 各路口信控方案 |
| `crossFlow` | Object | 是 | 各路口交通流量 |

## 2. 路口信息 (crossInfo)

### 2.1 格式结构
```
"路口ID": "渠化信息;相位信息"
```

### 2.2 渠化信息格式
```
方向ID,车道转向编码,出口道数|方向ID,车道转向编码,出口道数|...
```

**字段说明**:
- **方向ID**: 1=北, 2=东, 3=南, 4=西
- **车道转向编码**: 十六进制字符串，每个字符代表一个车道
  - 每个字符的4位二进制从高位到低位：掉头(8)、左转(4)、直行(2)、右转(1)
  - 示例: 
    - `7` = `0111` = 左转+直行+右转
    - `4` = `0100` = 仅左转  
    - `2` = `0010` = 仅直行
    - `1` = `0001` = 仅右转
    - `F` = `1111` = 全转向
- **出口道数**: 该方向的出口车道数量

**示例解析**:
```
"1,422,2|2,441,2|3,221,2"
```
- 方向1(北): 车道转向`422` = [左转, 直行, 直行], 出口道数2
- 方向2(东): 车道转向`441` = [左转, 左转, 右转], 出口道数2  
- 方向3(南): 车道转向`221` = [直行, 直行, 右转], 出口道数2

### 2.3 相位信息格式
```
相位ID+转向信息|相位ID+转向信息|...
```

**转向信息格式**:
```
方向ID+转向编码
```

**转向编码映射**:
- `1` = 右转
- `2` = 直行  
- `4` = 左转
- `8` = 掉头

**示例解析**:
```
"A3212|B14|C25"
```
- 相位A: 方向3允许转向2(直行), 方向2允许转向1(右转)
- 相位B: 方向1允许转向4(左转)
- 相位C: 方向2允许转向5(左转+右转, 因为5=4+1)

## 3. 信控方案 (planInfo)

### 3.1 格式结构
```
"路口ID": "相位时长配置,协调相位偏移"
```

### 3.2 相位时长配置
```
相位ID+持续时间(秒)+相位ID+持续时间(秒)+...
```

**示例**:
- `A59B32C39` = A相59秒 + B相32秒 + C相39秒

### 3.3 协调相位偏移
```
协调相位ID+绝对偏移(秒)
```

**示例**:
- `A10` = 协调相位为A，绝对偏移10秒

**完整示例**:
```
"A59B32C39,A10"
```
表示：A相59秒、B相32秒、C相39秒，协调相位为A，偏移10秒。

## 4. 交通流量 (crossFlow)

### 4.1 格式结构
```
"路口ID": {
  "方向ID+转向编码": 流量(veh/h),
  ...
}
```

### 4.2 转向编码
- `1` = 右转
- `2` = 直行
- `4` = 左转  
- `8` = 掉头

**示例**:
```json
{
  "C0": {
    "21": 55,   // 方向2右转，55辆/小时
    "24": 85,   // 方向2左转，85辆/小时  
    "28": 20,   // 方向2掉头，20辆/小时
    "14": 35,   // 方向1左转，35辆/小时
    "18": 40,   // 方向1掉头，40辆/小时
    "12": 140   // 方向1直行，140辆/小时
  }
}
```

## 5. 路段参数 (roadLength, roadSpeed)

### 5.1 路段长度 (roadLength)
- 数组长度 = 路口数量 - 1
- 按照`crossList`中路口的顺序定义

**示例**:
```json
{
  "crossList": ["C0", "C1", "C2"],
  "roadLength": [500, 600]
}
```
- C0到C1: 500米
- C1到C2: 600米

### 5.2 路段速度 (roadSpeed)
- 二维数组: `[[正向速度], [反向速度]]`
- 速度单位: km/h
- 如果未提供，默认使用系统常量

**示例**:
```json
{
  "roadSpeed": [[50, 55], [45, 50]]
}
```
- 正向(C0→C1→C2): 50km/h, 55km/h
- 反向(C2→C1→C0): 45km/h, 50km/h

## 7. 验证规则

### 7.1 必填字段验证
- `crossList` 至少包含1个路口
- `roadLength` 长度 = `crossList.length - 1`
- 每个路口必须在 `crossInfo`, `planInfo`, `crossFlow` 中都有定义

### 7.2 数据一致性验证
- 路口ID在所有字段中必须一致
- 转向编码必须在有效范围内 (1,2,4,8及其组合)
- 相位ID在 `crossInfo` 和 `planInfo` 中必须匹配
- 流量值必须为非负数

### 7.3 逻辑验证
- 协调相位必须在相位列表中存在
- 路段长度必须为正数
- 速度值必须在合理范围内 (10-120 km/h)
